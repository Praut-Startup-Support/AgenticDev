Poslední události

Čeká na tvoje rozhodnutí

Agent narazil na volbu, kterou nemá v politice pokrytou, a zastavil se. Tvoje odpověď se uloží jako ADR a příště se nabídne jako precedent.

Nový úkol

Bez DoD úkol nezaložím. Agent by neměl jak poznat, že skončil.

Všechny úkoly

Klikni na úkol a uvidíš, co se s ním dělo krok po kroku.

Nový projekt

Bez diakritiky a mezer. Použije se jako název git repa.

Projekty

Připojení nového stroje

Pošli tenhle odkaz. Funguje z celého světa, pro macOS, Linux i Windows:

–

Heslo pro připojení posílej zvlášť, jiným kanálem než odkaz. Najdeš i změníš ho v Nastavení → Přístup. Po doběhnutí má člověk na ploše ikonu AgenticDev a nic dalšího nepotřebuje.

Čekají na účet

Kdo se ohlásil na registrační stránce. Účet na VPS zakládáš ty: agenticdev-ctl user add <login>

Pracovní stanice

Nouzové zastavení

Zastaví vydávání nových work orderů. Rozdělaná práce dojede do nejbližšího checkpointu.

Nastavení

Změny platí okamžitě, restart není potřeba. Hesla se zobrazují zamaskovaná — pole nech být, pokud ho neměníš.

Jen ke čtení

Tyhle hodnoty se čtou při startu. Mění se v /srv/agenticdev/config/.env a pak agenticdev-ctl up.
