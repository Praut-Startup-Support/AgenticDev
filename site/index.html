Správa opouští notebook a stěhuje se na server. Governance moves off the endpoint and onto the server.

01policy → grant

Fáze určuje pravidlaPhase sets the rules

Server čte aktuální fázi projektu a z ní přesně odvodí, co agent směl dělat. Notebook se nikdy neptá — poslouchá. The server reads the current project phase and derives exactly which capabilities the agent is allowed to use. The laptop never asks — it obeys.

02spawn → destroy

Práce běží v jednorázovém kontejneruWork runs disposable

Každý úkol běží ve svěžím, zahoditelném kontejneru. Až skončí, prostředí se zničí. Žádný zbytek, žádný přístup navíc, žádný přenesený stav. Every task executes inside a fresh, throwaway container. When it ends, the environment is destroyed. No residue, no lingering access, no state carried forward.

03append → seal

Rozhodnutí se pečetíDecisions are sealed

Udělení, zamítnutí, eskalace — každé rozhodnutí se zapíše do append-only evidence s hashem. Plně auditovatelné, navždy. Grant, deny, escalate — each decision is written to an append-only ledger with its inputs and hash. Fully auditable, forever.

// jen přidáváníappend-only

Každé rozhodnutí končí v auditovatelné evidenci. Every decision lands in an auditable ledger.

Nic, co agent udělá, není mimo záznam. Každé udělení, zamítnutí i eskalace se zapečetí se svými vstupy a zřetězeným hashem — nezfalšovatelně a přehledně i dlouho po tom, co kontejner zmizí. Nothing the agent does is off the record. Each grant, denial, and escalation is sealed with its inputs and a chained hash — tamper-evident and reviewable long after the container is gone.
